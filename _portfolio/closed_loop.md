## Overview

This project explores how noisy EEG signals can be transformed into stable control states for closed-loop brain–computer interface systems.

## Approach

- Designed an EEG-driven 2D cursor control framework using the BCI Competition IV-2a dataset.
- Combined supervised neural decoding with reinforcement learning-based sequential decision-making.
- Proposed a compact neural representation that compresses high-dimensional EEG features into a low-dimensional control state.
- Integrated neural features, decoder outputs, and task geometry into a structured state representation.

## Key Findings

- Improved training stability and convergence compared with conventional approaches.
- Improved robustness to EEG noise.
- Demonstrated stable neural control behavior in simulated cursor-control tasks.
- Ongoing work evaluates cross-dataset generalizability across multiple BCI datasets.

## Takeaway

This project shows that compact neural representations are critical for building robust and generalizable closed-loop neural control systems.
